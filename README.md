# SkinLuxe — Astro

إعادة بناء الصفحة الرئيسية لتصميم SkinLuxe بـ Astro وCSS وTypeScript، بلا React أو مكتبات Animation إضافية.

## التشغيل

من داخل مجلد `skinluxe`:

```sh
npm install
npm run dev -- --background
```

المعاينة: http://localhost:4321/

```sh
npm run dev -- status
npm run dev -- logs
npm run dev -- stop
npm run build
```

`npm run build` كيولّد نسخة Static جاهزة للاستضافة داخل `dist/`.

## فين نبدّل الكود؟

- `src/pages/index.astro`: كيجمع الصفحة كاملة.
- `src/components/`: كل قسم فملف مستقل؛ `Hero`, `About`, `Services`, `Results`, `Testimonials`, `Footer`.
- `SectionHeading.astro`: عنوان قابل لإعادة الاستعمال باستعمال Props.
- `Header.astro`: القائمة ونافذة البحث.
- `OrderForm.astro`: معلومات الشراء والتوصيل، مرتبط بزر «تواصلي معنا» و«تسوقي الآن».
- `src/data/product.ts`: ثمن الوحدة (250 درهم) ورقم WhatsApp بصيغة دولية.
- `src/lib/order.ts`: إعداد رسالة طلب الشراء وحساب مجموع المنتجات حسب الكمية.
- `src/styles/global.css`: الألوان والخطوط وResponsive والـ Animations.
- `src/scripts/interactions.ts`: Accordion، قائمة الهاتف، مقارنة قبل/بعد، الشهادات، البحث والعدّادات.
- `public/images`, `public/fonts`, `public/video`: الأصول المحلية.
- `scripts/download-assets.mjs`: المصادر الأصلية للأصول المستعملة.

## المرجع والنطاق

التصميم والمحتوى والصور والخطوط والفيديو مأخوذين من النسخة المنشورة اللي تشاركات فالمحادثة:
https://predictable-let-589750.framer.app/

تمت إعادة بناء الواجهة والحركة بوسائل Astro الأصلية؛ الحركة تقريب بصري للسلوك المشاهد وليست تصديراً لمحرك Framer.

- الصفحة الرئيسية كاملة مع دعم RTL وMobile وTablet وDesktop.
- الخدمات، مقارنة الصور، الشهادات، البحث المحلي والقائمة قابلة للتفاعل ولوحة المفاتيح.
- الفيديو الأصلي كيتشغّل تلقائياً عند ظهوره وكيوقف خارج الشاشة، مع زر التشغيل والإيقاف.
- `prefers-reduced-motion` كيوقف الحركة غير الضرورية والتشغيل التلقائي للفيديو.
- Newsletter واجهة فقط؛ ما كيتصيفط حتى بريد وما كيتخزن حتى عنوان، وكتظهر رسالة واضحة عند المحاولة. خاص ربط خدمة بريد لتفعيل الاشتراك الحقيقي.
- المتجر والمجلة مرتبطين بأقسام الصفحة؛ ما كاينش متجر أو دفع أو CMS فهاد النسخة. الروابط الأصلية ديالهم كانت كترجع للصفحة الرئيسية.
- فورم الشراء كيفتح مسودة WhatsApp فيها المنتج والثمن والكمية ومعلومات الزبون. الزبون خاصو يضغط إرسال داخل WhatsApp باش يوصل الطلب. ما كاينش أداء أوتوماتيكي أو تخزين محلي للبيانات. مصاريف التوصيل كتتأكد بشكل مستقل.
- Social links هي الروابط العامة الموجودة فالتصميم، ماشي حسابات خاصة بالعلامة.
- الإحصائيات وشهادات العميلات ومقارنة الصور محتوى القالب الأصلي، ماشي نتائج مثبتة لمنتج جديد.

## التحقق

تم فحص Build، الصور المحلية، Accordion، المقارنة بالـ Keyboard، قائمة الهاتف، الشهادات، البحث، الفيديو ووضع تقليل الحركة. تم فحص عرض 320 و390 و768 و1440px.

تم التحقق محلياً من حساب الثمن وترميز رسالة WhatsApp والروابط. اختبار فورم الشراء الأخير فالمتصفح ما تنفّذش لأن طلب تشغيله ترفض؛ ما تصيفطات حتى رسالة تجريبية.
